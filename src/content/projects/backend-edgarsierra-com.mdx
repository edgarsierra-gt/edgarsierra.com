El backend de este sitio es intencionalmente un case study de ingeniería GCP. Demuestra el patrón de deploy con Workload Identity Federation: las GitHub Actions se autentican ante GCP sin almacenar llaves JSON, usando tokens OIDC efímeros que GCP valida directamente contra el repositorio autorizado.
