Experimento público de estadística aplicada durante el Mundial 2026. El pipeline genera probabilidades 1X2, goles esperados, escenarios de clasificación, simulación de rondas, auditoría del modelo y archivos JSON consumidos por el sitio.

El objetivo no es vender picks ni prometer certeza. Es mostrar cómo se construye un sistema probabilístico trazable: datos normalizados, modelo Poisson, simulación Monte Carlo, outputs versionados y una capa editorial que explica incertidumbre sin lenguaje de apuestas.
